## Setup

Run the commands from the package root with CPython **3.11.16**, CUDA 12.8 and NVIDIA driver
595.99.02:

```bash
python -m venv .venv
. .venv/bin/activate
pip install --index-url https://download.pytorch.org/whl/cu128 torch==2.10.0
pip install -r 1.Code/requirements.txt
```

Pinned libraries are listed in `1.Code/requirements.txt` (`transformers==5.11.0`, `peft==0.20.0`,
`accelerate==1.15.0`, `numpy==2.2.6`, `decord==0.6.0`, `qwen-vl-utils==0.0.14`, `jinja2==3.1.6`,
and the tokenizer/video decoder stack). `1.Code/Dockerfile` builds the same environment.

server.

## Run the supplied pipeline

Staging verifies the base weight, all 568 videos and the adapter before writing anything, then
produces a working directory whose `infer.py` differs from `1.Code/code/infer.py` in one line only
(the hard-coded video directory becomes the one passed in). Use a fresh external directory:

```bash
python -X utf8 1.Code/verification/prepare_runtime.py \
  --work-dir ../ComTrackB_work \
  --base-dir /path/to/base-4b --videos-dir /path/to/quantiphy/videos
```

Then run the printed commands, or equivalently:

```bash
CUDA_VISIBLE_DEVICES=0 python -X utf8 ../ComTrackB_work/student/infer.py --job student --smoke
CUDA_VISIBLE_DEVICES=0 python -X utf8 ../ComTrackB_work/student/infer.py --job student
```

The full run writes `TRACKB-FROM0863-MAIN7493-LR2E5-E1-UNTESTED.csv` plus the generation journal
under `../ComTrackB_work/student/epoch1-infer32f-czq/`. Expected CSV SHA-256:
`1216ece8fae28f39431a719973794381d29e813214eacbcb66a1da82cb5d5b56`. The run is resumable: rows
already present in the journal are skipped, and it loads the model once per invocation.

To rebuild the training-side 16-frame cache instead, add `--rebuild-cache` and a different
`--work-dir`; all 568 reconstructed `.npy` files are compared with
`1.Code/provenance/CACHE_SOURCE_MANIFEST.json` and the run fails on any mismatch. Nothing is
uploaded.

## Hardware and runtime

**Hardware used:** one Linux server with 8 × NVIDIA RTX 6000D, 85,651 MiB per GPU, driver 595.99.02,
CUDA 12.8. The recorded training and inference jobs targeted GPU 0. Inference asserts more than
45 GiB free GPU memory; the frozen training plan required at least 80 GiB.

**Approximate runtime:** training one epoch (3,289 rows, 412 optimizer steps) took 10,114 s
(2 h 49 min). Inference on 3,289 items took 5,478.92 s (91 min 19 s), measured on the full replay of
2026-10-28; the original window was approximately 96 min. Rebuilding the 568-file frame cache takes
a few minutes. The offline audit takes under a minute on CPU.

identity, pure-LoRA and base-tensor compatibility, original code hashes with the LoRA-only training

replay. It passes all seven; the result is `1.Code/verification/AUDIT_REPORT.json`.

and the full 3,289-question rerun completed with no parse failures, and the CSV, generation journal
and frozen predictions were reproduced byte-for-byte. The 16-frame training cache was rebuilt with
all 568 hashes matching. Records: `1.Code/provenance/SERVER_VERIFICATION_20261028.json` and
`1.Code/verification/SERVER_RUN_20261028.json`. The one-epoch training run itself was not re-executed.
